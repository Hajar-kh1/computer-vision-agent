# Package Damage Detection — Production Computer Vision Agent

> Weekly group project: build and deploy a **production-oriented AI application**
> that classifies images of shipping packages as **damaged** or **undamaged**
> and exposes the model through a real software system.
>
> Spec: `weekly_cv_production_agent_projectweek.md` (instructor brief).

## Project Overview (TODO — fill in)

- **Goal:** classify package images (damaged / undamaged) end-to-end: data → model → API → database → frontend → agent chat → production deployment.
- **Domain:** Computer Vision + MLOps + Backend + Agentic AI + Deployment.
- **Team:** 4 students (CV Engineer · Backend/Database · Agentic AI · Frontend/DevOps).
- **Final deliverable:** a working AI product from data to production — **not a notebook**.

## Repository Structure

```text
package-damage/
├── README.md            <- this file
├── pyproject.toml       <- uv-managed Python deps (root)
├── uv.lock              <- generated by `uv lock` (commit it)
├── .env.example         <- env var template (never commit real secrets)
├── .gitignore
├── compose.yaml         <- Docker Compose: postgres + backend + frontend + open-webui
│
├── data/
│   ├── raw/             <- downloaded dataset (train/val/test or per-class folders)
│   ├── processed/       <- cleaned/split dataset
│   └── README.md        <- dataset documentation (source, counts, license...)
│
├── training/            <- Student 1: CV Engineer
│   ├── dataset.py
│   ├── transforms.py
│   ├── train.py
│   ├── evaluate.py
│   └── download_dataset.py
│
├── models/              <- model.pt + labels.json (+ metrics)
│
├── backend/             <- Student 2: Backend & Database Engineer
│   ├── Dockerfile
│   └── app/
│       ├── main.py, config.py, database.py, models.py, schemas.py
│       ├── api/         <- health, predictions, history, stats, model_info
│       ├── services/    <- inference.py, prediction_service.py
│       └── tools/       <- agent tool implementations
│
├── agent/               <- Student 3: Agentic AI Engineer
│   ├── agent.py, tools.py, prompts.py
│
├── frontend/            <- Student 4: Frontend & DevOps Engineer
│   ├── Dockerfile, package.json
│   └── src/             <- React + Vite (Classify, History, Dashboard views)
│
├── openwebui/           <- Open WebUI integration notes + function files
├── tests/               <- pytest suite
├── docs/                <- architecture.md, api.md, demo.md
└── deployment/          <- Dokploy deployment notes
```
