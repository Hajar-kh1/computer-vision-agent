# Model Artifacts

This folder holds the trained model and class mapping used by the backend
inference service (spec §13).

## Files
| File | Contents |
|---|---|
| `model.pt` | Trained model (torch state_dict) — **generated by `training/train.py`**, not committed to Git |
| `labels.json` | Class mapping, e.g. `{"0": "damaged", "1": "undamaged"}` |
| `model_metrics.json` | Optional copy of `reports/model_metrics.json` for `GET /api/v1/model` |

## Contract (must match backend)
- Input: RGB image resized to the training input size (default 224×224),
  ImageNet-normalized — same transforms as `training/transforms.py`.
- Output: class index → label via `labels.json`, plus softmax probabilities.
